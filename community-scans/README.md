# Community Cape Scans

Place high-quality flatbed scans of LEGO capes and fabric accessories here.

## Scan Guidelines

- **600 DPI** minimum (higher is better)
- Lay the cape completely flat on the scanner bed
- Include a ruler or known-scale reference object if possible
- Scan both sides if the fabric has a distinct front/back
- Save as **PNG** (lossless) — avoid JPEG compression

## File Naming

Use the format: `PartNumber_Description.png`

Examples:
- `522px1_Standard_Black_Cape.png`
- `99464_Tattered_Brown_Cape.png`
- `Unknown_Custom_Satin_Cape.png`

## How to Contribute

1. Fork this repository
2. Add your scan(s) to this folder
3. Open a pull request with the LEGO part/set number if known

All contributors will be credited in the project README.
